## Root cause and bounded repair

The prior disclosure-only repair could reveal the form but could not enable it.

The shared loader now resolves the saved/current/default offered mode before the optional COD read. An online review uses its own server quote; a COD option is selectable only when `codQuoteMatches` agrees with current server options.
