Cart: drawer + `/[locale]/cart` page over the EXISTING multi-SKU cart/quote backend (grep internal/storefront/cart.go, quote.go and the storefront BFF — reuse, do not create a second cart), line qty edit/remove, subtotal, free-shipping progress text when the policy has a threshold, Checkout → the existing order flow (OrderFlow).
