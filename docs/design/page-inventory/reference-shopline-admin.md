# SHOPLINE 商家后台参照（视觉与版面）

用法：这是**参照，不是照抄**。可借的是结构、密度与交互习惯（商家熟悉、零学习成本）；品牌层（logo、主色）用 DaWan 自己的；不复制 SHOPLINE 图标与图形资产。
测量来源：3498 px 宽、DPR≈2 的整屏截图（CSS 视口约 1749 px），取色为区域众数；尺寸为 CSS px 近似值（±2 px）。证据级 E2（实测截图）。

## 1. 外壳（App shell）

| 部位 | SHOPLINE 做法 | 量值 |
|---|---|---|
| 左侧主导航 | 深色常驻侧栏，顶部 logo 条 + 店铺卡（logo、店名、地区），下面是一级菜单（图标 + 文字 + 折叠箭头），展开后二级菜单缩进、无图标 | 宽 ≈ 270 px；底色 `#373D4C`；当前项 `#494F5D`；logo 条 `#4C5561`；文字白色/浅灰；一级项高 ≈ 52 px |
| 顶栏 | 白色细条：语言切换、帮助（下拉）；右侧通知、公告、「进入我的商店」、账号下拉 | 高 ≈ 50 px；底 `#FDFDFD` |
| 面包屑 | 顶栏下方一行：`商品及分类 › 商品 › 增加`，前级灰、当前级深色 | 父级 `#777777`；字号 ≈ 18 px |
| 页面底色 | 浅灰，内容放在白卡片里 | `#F8F8F8`；卡片 `#FFFFFF`，1 px 浅边/极淡阴影，圆角 ≈ 4 px |
| 「新手上路」进度 | 侧栏首项，带黄色「尚未完成」胶囊 | 胶囊底 `#FAE2A9`、深色字 |

## 2. 列表页（商品列表）

- 顶部：数量「837 / 无限」+ 右上次要按钮（报表、分析）。
- 一条说明横幅（白卡片，正文灰）。
- 主卡片标题行：蓝色标题「商品列表」+ 帮助问号；右侧按钮组 `汇出`（次要）`汇入 ▾`（次要下拉）`+ 增加`（主按钮，蓝）。
- 筛选行：「显示: 所有商品 ▾」「全部 ▾」+ 搜索框（右侧放大镜按钮）+ 分隔 + 「批量上下架/变更 ▾」。
- 表格：首列复选框；缩略图 ≈ 86 px 方图；列为原价格、特价、网店数量（∞ 表示不追踪）、商品名称、状态图标；行高 ≈ 98 px；行分隔线 `#DDDDDD`；表头字深灰小号无底色。
- 行操作放最右：`网店下架`（次要）`实体店上架`（蓝色实心）`编辑`（次要）`▾`（更多）。**一行最多一个蓝色主按钮**。

## 3. 表单页（新增/编辑商品）

- **上下两条操作条**（同内容重复在顶部和底部）：左侧说明「填写商品资料后，按下『增加』或『更新』保存」，右侧状态开关「网店上架 [是|Ⅲ]」「实体店上架 [是|Ⅲ]」+ 蓝色主按钮「增加/更新」。
- **页签式分区**（不是长滚动锚点）：主要图片 · 商品信息 · 分类 · 数量和价格 · 商品规格 · 加购品 · 搜索引擎优化 · 设定 · 产品规格摘要 · Metafields；当前页签白底，其余灰底。
- 分区标题蓝色 + 帮助问号，右侧计数（`0 / 12`）。
- 图片上传：大虚线拖放区「拖放图片到这里」+ 格式与建议尺寸一行说明 + 两个按钮（新增图片、从图片库中选取）。**格式/尺寸要求在上传前就写清楚**。
- 开关：绿色分段开关（`#74B666` 的「是」块 + 白色「Ⅲ」块），不是 iOS 圆点开关。

## 4. 设置页（直播关键字设定，旧截图）

- 页头：返回箭头方块 + 大标题 + 帮助问号。
- 白色大卡片内**左侧二级导航**（分组标题 + 子项，当前子项左侧蓝色竖条 + 浅蓝底），右侧内容区。
- 内容：小节标题 + 单选组（选项文字里关键词加粗，后跟「查看示例」链接）。
- 底部右下：`取消`（白）`保存变更`（蓝；无改动时为浅蓝禁用态）。

## 5. 总览（Dashboard）

- 顶部页签（网店 / 实体店，下划线式）。问候语大标题。
- 三张 KPI 卡（图标 + 大数字 + 标签：留言未读、订单未出货、订单未付款），**可点进对应列表**。
- 「今天」日期下拉 + 「更多数据」；图表卡含分段切换（成交总额 | 总营业额），涨幅绿字「↑130% 相较昨天」。

## 7. 可借（portable） / 不借

- **可借**：深色侧栏 + 白卡片的分层；面包屑；列表页「标题行按钮组 + 筛选行 + 批量下拉 + 行内操作」结构；表单页签分区 + 顶/底双操作条；上传前写明格式和尺寸；设置页「卡片内左侧二级导航」；KPI 卡可点进列表；每行最多一个主按钮。
- **不借**：SHOPLINE logo、图标与插画；把直播/消息做成 iframe 微前端（本项目是单体，见 2026-10-02 研究）；「Ⅲ」这类含义不清的开关符号（改用「否」文字）；两条完全重复的操作条在移动端的布局（移动端只保留底部吸附条）。
