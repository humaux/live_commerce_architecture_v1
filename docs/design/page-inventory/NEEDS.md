## 3. 跨页通用模式（设计系统）

| 模式 | 要求 | 使用页面 |
|---|---|---|
| 列表 + 筛选 + 批量 | 筛选和分页游标写进 URL；全选时区分「本页」和「全部筛选结果」并要求确认（[07 §5.1]）；批量结果逐项回报 | P01 P02 P05 P08 P11 P12 P13 P16 P22 P29 P32、发货中心、P38/P39/P49/P51（买家版） |
| 分段表单 + 底部保存栏 | 保存栏常驻；有未保存改动要提示；版本冲突时提示重新加载；结果不确定时可重试（同一幂等键） | P03 P06 P10 P14 P17 P19 P23 各设置页 P26 P29 P32 |
| 详情 + 时间线 | 主体信息、可执行的操作、审计/事件时间线 | 订单详情 P06 P12 P22 P25 P44 场次详情 |
| 向导 | 分步、可返回、步骤间保留输入，最后一步预览再提交 | P04 P07 场次详情 开店流程 P31 P34 P36 |
| 导入预览 → 确认 → 失败下载 | 上传、列映射、试运行、确认、导出失败行 | P04 P07 运单回填 收货资料导出 |

## 4. 重设计优先级

| 顺序 | 模块 | 理由 |
|---|---|---|
