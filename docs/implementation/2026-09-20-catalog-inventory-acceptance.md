## 发现并修复，不删失败测试

- CreateSKU 缺初始价格历史：补同事务版本 1 记录，独立测试从失败变通过。
- BEFORE INSERT 库存触发器会在 ON CONFLICT DO NOTHING 跳过流水时先改余额：改 AFTER INSERT，真实冲突测试验证余额及版本不变。
- 审计主体伪造、SKU 海关确认字段越权：actor restrictive RLS 与列级 INSERT 权限，真实负测 42501。
- 旧二进制未拒绝未来迁移：双向核对 ledger 与嵌入版本集合，错误时零变更。
- 同键请求等待超过行锁 1 秒：命令锁使用总请求期限并恢复原行锁超时；持锁 1.2 秒的并发回放通过。
- 非指针/typed-nil 命令结果提前拒绝，不执行业务。
- 主线第一次集成测试因新 HTTP 测试多余导入失败，移除无用导入后完整复跑，未放宽断言。
